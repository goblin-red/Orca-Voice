# Orca Voice

[English](README.md) · **Русский**

Голосовой пульт для агентов-программистов в [Orca](https://github.com/stablyai/orca) на macOS.
Сказали слово — и во вкладку Orca в фокусе уходит пробел или Enter. Можно надиктовать запрос,
перейти на следующую вкладку с агентом и послушать его ответ. Руки остаются свободными.

- **Голосовые команды** — пробел, Enter, следующая вкладка с агентом, остановка голоса. Слова выбираете сами.
- **Голосовой ввод** — всё, что вы говорите, печатается во вкладку в фокусе; закончите фразу словом-Enter, и она уйдёт агенту.
- **Озвучка ответов** — когда агент (Claude, Codex, OpenCode) закончил, голос macOS читает его ответ.
- **Работает на компьютере** — речь распознаёт [whisper.cpp](https://github.com/ggml-org/whisper.cpp) прямо на вашем Mac.
- **Два языка окна** — русский и английский, переключаются кнопками RU / EN в шапке окна.

## Что нужно

- macOS 13 или новее
- [Orca](https://github.com/stablyai/orca) и его команда `orca` в `PATH`
- Python 3 (разработано и проверено на 3.14)
- whisper.cpp: `brew install whisper-cpp` (даёт `whisper-server`)

## Установка

```sh
git clone https://github.com/goblin-red/orca-voice.git
cd orca-voice

# окружение Python
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# модель Whisper (около 190 МБ)
mkdir -p models
curl -L -o models/ggml-small-q5_1.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small-q5_1.bin
```

## Запуск

```sh
./start.sh     # или двойной клик по «Orca Voice.app» в этой папке
./stop.sh      # крестик окна тоже завершает всё целиком
```

При первом запуске macOS спросит доступ к микрофону. Настройки сохраняются в `config.json`,
он создаётся из `config.default.json` при первом запуске. Окно открывается на английском —
нажмите RU в шапке, а язык распознавания выберите в «Настройки → Распознавание (Whisper) → Язык».

## Голосовые команды

| Слово по умолчанию | Что делает |
| --- | --- |
| «дамбл-бамбл» / `dumble bumble` | Пробел во вкладку в фокусе (в Claude с включённым `/voice` — начать или закончить запись) |
| «рекс» / `rex` | Enter — отправить сообщение агенту |
| «переключи терминал» / `switch terminal` | Перейти на следующую вкладку с агентом в активном проекте, по кругу |
| «заткнись» / `shut up` | Прервать голос, пока он читает ответ |

У каждой команды — список вариантов: так Whisper может расслышать слово. Сравнение нечёткое
(по «скелету» из согласных), небольшие отличия не мешают. Если слово не срабатывает, посмотрите
строку «Услышано» на пульте и добавьте это написание в **«Настройки → Голосовые команды»**.

Без голосового ввода говорите команду отдельной короткой фразой. С голосовым вводом её можно
сказать в конце предложения: «сделай аудит проекта, рекс».

## Языки

- **Окно** — кнопки RU / EN в шапке. Они переключают окно, статусы, журнал и служебные фразы голоса.
- **Распознавание** — отдельная настройка: **«Настройки → Распознавание (Whisper) → Язык»**.
- **Голос** — выберите голос macOS того языка, на котором отвечают ваши агенты.

## Режим OpenAI (экспериментальный)

Кроме Whisper на компьютере есть облачный режим: звук микрофона уходит в сервис распознавания
речи OpenAI. Ключ API не нужен — используется **ваша собственная** подписка ChatGPT через вход Codex
на вашем компьютере (`codex login`, он создаёт `~/.codex/auth.json`). В репозитории ничьих ключей
нет — каждый входит под своей учётной записью.

Важно:

- Это неофициальный, недокументированный адрес. Он может измениться или перестать работать в любой
  момент; пользуетесь им на свой риск.
- В этом режиме звук микрофона уходит в OpenAI. В штатном режиме весь звук остаётся на вашем Mac.

## Файлы

| Файл | Зачем |
| --- | --- |
| `app.py` | Ядро: окно, режимы, команды, настройки |
| `listener.py` | Микрофон и детектор речи |
| `whisper_srv.py` | Запускает `whisper-server` и отдаёт ему фразы |
| `matcher.py` | Ищет слова-команды в распознанном тексте |
| `orca_cli.py` | Работа с Orca через его CLI |
| `speaker.py` | Следит за агентами и читает их ответы вслух |
| `live.py` | Режим OpenAI |
| `settings_server.py` | Локальный сервер (127.0.0.1) для окна |
| `ui.html`, `ui_texts.js` | Окно и его тексты на двух языках |
| `i18n.py` | Статусы, журнал и фразы голоса на двух языках |
| `config.default.json` | Настройки по умолчанию |
